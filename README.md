# Fast Bots

A Fabric mod for Minecraft Java 26.2 by **redishpurple**.

Carpet fake players (`/player <name> spawn`) normally look every name up on
Mojang's servers and download its skin before they join. For made-up bot
names that lookup fails slowly, which throttles big bot armies to about 3
spawns a second and can freeze the server. Fast Bots skips the lookup for
names with no Mojang account, so hundreds of bots spawn in seconds.

Made for **Unstable Arena**, the PvP bot map.

## Requirements
- Minecraft Java 26.2
- Fabric Loader 0.19.5+
- [Carpet](https://modrinth.com/mod/carpet)

## Install
Download `fast-bots-1.0.0.jar` from the
[Releases](../../releases/latest) page and put it in your `mods` folder.
